# NIT Jamshedpur 1998 Batch Reunion

Static attendee-actions website for the January 2027 reunion.

## Publish with GitHub Pages

1. Push this repository's `main` branch to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub Pages will publish the site at `https://p2technikal.github.io/2027AlumniMeetNITJSR/`.

The site entry point is `index.html`; its images and downloadable template are in `assets/`.
